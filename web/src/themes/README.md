# 乐见极简

网页入口通过 `load.ts` 加载乐见极简（`joysee-minimal`）。前后端共用 `backend/internal/app/appearance_theme_packs.json` 中的皮肤参数。管理员在「站点及外观 → 皮肤主题」编辑浅色、深色及控件参数。

旧外观配置中已保存的乐见极简参数会继续生效。缺少该套皮肤时使用内置参数，站点名、Logo、登录视频和封面仍按站点配置显示。画布主题预设用于新建画布，已有画布继续读取各自保存的外观。

龙影水墨和云鹤仙观的源码与静态资源保留供旧版本使用。插图及字体的来源与许可见 `public/themes/README.md`。
