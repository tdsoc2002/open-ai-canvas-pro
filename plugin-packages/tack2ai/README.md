# 源点动力 · 影策插件

通过源点动力已有的 OpenAI 通用协议生成文字、图片、视频和语音。一个安装包，四个调用协议，不修改网关，不包含 API Key。

## 安装与配置

1. 在影策插件中心上传 `tack2ai.yingce-plugin`，由管理员开放并按当前安装页面启用。
2. 新建或编辑渠道：地址填 `https://ai.tack2ai.cn`（也可填自己的网关地址），填写源点动力 API Key；不要在地址中携带密钥。
3. 官方地址的 OpenAI 系统渠道可在「渠道与模型 → 拉取模型」读取当前 Key 可见的目录，选择可导入的模型；目录声明且影策支持的能力会被预填。其他地址按原有流程手动选择下表协议。
4. 新条目停用、未定价；已有模型不会被覆盖。核对实际能力、成本和售价后再启用。不自动导入价格或额度。

| 任务 | 调用协议 | 入口 |
| --- | --- | --- |
| 文字 | 源点动力文字 | `/v1/chat/completions` |
| 图片 | 源点动力图片 | `/v1/images/generations`、有参考图时 `/v1/images/edits` |
| 视频 | 源点动力视频 · OpenAI | `/v1/videos`，查询及下载原任务 |
| 语音 | 源点动力语音 | `/v1/audio/speech` |

视频请选择固定时长；普通比例或像素尺寸均按本网关现有 OpenAI 入口处理。保持影策的通用「出声」「水印」开关关闭：模型专用参数通过 `tack2ai-video.metadata` 显式配置，避免猜测字段名。不支持草稿转正式或拼车管理。

图片可按模型目录使用像素尺寸，也可选择独立的分辨率档位和宽高比。语音不默认套用 `alloy`；只发送有效配置或显式输入的音色。只有明确声明支持的语音模型才能用参考音频或图片（不能混用，也不能同时指定音色）。不包含音乐生成、转写或创建音色资源。文字第一版使用 Chat Completions，不新增 Responses 专用协议。

## 安全与验证边界

- 所有鉴权、出站检查、下载和本地保存交给影策宿主；不执行插件脚本、不绕过权限或计费。
- 不使用 `X-TD-Contract` 或 TD 专用请求体。视频多素材 `references`、分辨率 `resolution_name` 是源点动力已有的 OpenAI 兼容扩展，并非 OpenAI 官方通用字段。
- 参考视频/音频及签名素材地址必须能被网关访问；本机资源不能仅因插件安装成功就变成公网可访问。
- 生成失败、下载失败和无结果均不能当作保存成功；视频恢复查询原任务，不自动重投收费任务。
- 本地模拟上游验证不代表目标网关版本、真实模型、权限、余额或公网素材已通过验收；不自动发起收费调用。

完整字段、扩展参数及响应约定见 `docs/interface.md`。
