# 腾讯云 VOD VS 直连

本插件仅供管理员配置系统渠道，鉴权和视频请求由乐见画布服务端直连腾讯云，不经过源点动力，也不会在用户侧显示腾讯凭据。腾讯临时视频结果仍经任务管道写入平台已配置的对象存储。

1. 后台进入「渠道与模型」，新建系统渠道，点击「使用腾讯云 VOD VS 直连」，填写点播应用 ID（SubAppId）、SecretId（`apiKey`）、SecretKey（`secretKey`）。
2. 在该渠道添加视频模型，选择「腾讯云 VOD VS 直连」接口协议，上游模型填 `2.0`、`2.0-fast`、`2.0-mini` 或 `2.5`，设置平台售价和可用范围后再启用。
3. 凭据仅用有权操作对应点播应用的最小权限云账号；不使用聊天中披露过的密钥。
