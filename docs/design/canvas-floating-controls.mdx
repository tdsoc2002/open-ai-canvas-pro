# 画布浮动控件设计沉淀：顶部操作区与底部 Dock

> 范围：无限画布的顶部项目操作区、底部画布工具 Dock、小地图，以及工作模式切换。
> 目标：让画布操作控件形成统一的浮动面板系统，并在不同主题和视口下保持稳定对齐。
> 状态：已实现首版，构建与当前画布回归已确认。

## 1. 设计方向

画布本身是创作空间，操作控件不应占用固定内容栏，也不应把按钮散落在画布节点之间。因此控件采用独立浮动面板：

- 左上放置项目菜单、画布名称和重命名入口。
- 右上放置搜索、导入、性能、积分、专注、分享和 Agent 等操作。
- 左下保留画布视图控制和素材空间 Dock。
- 工作模式切换放在右下，与左下 Dock 共用底部安全区，避免顶部中央出现额外的孤立控件。

## 2. 视觉合同

顶部操作区和底部 `FloatingDock`（浮动 Dock）复用 `canvasDockStyle`（画布 Dock 样式合同）：

- `--dock-surface`：浮动面板表面。
- `--dock-border`：主题边界。
- `--elevation-overlay`：面板层级阴影。
- `--dock-command-hover`：控件悬停表面。
- `--dock-command-active`：持续激活状态表面。

普通操作按钮默认透明，只有悬停或持续激活时才显示控件表面；面板本身负责边界和阴影，避免每个按钮都形成独立卡片。

## 3. 工作模式切换

`CanvasWorkspaceModeSwitch`（画布工作模式切换）是右下角独立浮动面板，不再挂在顶部栏中间：

- 触发器与底部 Dock 使用同一高度、圆角、边界和阴影。
- 菜单从触发器上方展开，并与右侧边缘对齐，避免遮挡底部工具栏和画布主体。
- 外层定位使用 `--canvas-inset-x` / `--canvas-inset-y`，与左下视图控制保持同一水平基线。
- 简洁模式和专业模式继续使用原有 `workspaceMode` 状态，不改变节点渲染和生成逻辑。

## 4. 实现地图

- `web/src/pages/canvas/canvas-project-top-bar.tsx`：顶部左右浮动面板，以及工作模式切换组件和下拉菜单。
- `web/src/pages/canvas/project.tsx`：将工作模式切换定位到画布右下角，并与底部控制使用同一安全区。
- `web/src/components/canvas/canvas-zoom-controls.tsx`：左下视图控制条。紧凑尺寸、无底板（样式见同目录 `canvas-zoom-controls.css`），不再作为浮动面板表面的基准。它测量底部一行后决定与主工具条同排（主工具条在其右侧剩余空间居中）还是抬到上一行，规则见 `canvas-overlay-layout.ts` 的 `canvasBottomRowLayout`。
- `web/src/components/canvas/canvas-mini-map.tsx`：小地图节点轮廓、视口边框和拖动导航。
- `web/src/components/canvas/canvas-overlay-layer.tsx`：画布浮层的激活层级管理，按点击和焦点提升当前浮层。
- `web/src/lib/canvas/canvas-aceternity-style.ts`：提供 `canvasDockStyle` 样式合同。
- `web/src/styles/globals.css`：维护顶部面板、控件状态和工作模式菜单的唯一样式规则。

### 乐见普通画布的左侧工具布局

- 左侧竖栏贴齐画布的左、上、下边缘。点击首行的品牌 Logo 打开画布菜单，整行与右侧 48px 顶栏对齐。画布名称位于顶栏，详情面板从顶栏下方展开。节点、素材库、任务、历史和添加节点排列在菜单下方，高度不足时可在栏内滚动，画布菜单固定在顶部。
- 竖栏中的节点、素材库、任务、历史和添加节点按钮采用圆角正方形，图标与文字上下居中。选中或展开时，图标显示圆角底色。按钮组内的上下间距为 12px。
- 「添加节点」菜单从竖栏向右展开，可以打开「姿势库」。若左侧详情面板已打开，展开菜单时先收起详情。按 Escape 关闭后焦点回到触发按钮。
- 选中节点后可用 Delete 或 Backspace 删除。「清空画布」从左上角画布菜单打开，执行前需要二次确认。
- 画布工具栏使用默认的工具顺序与显隐，旧的自定义偏好停止生效。
- 底部 Dock 靠左放置，「画布外观」位于指针工具旁，点击调色盘按钮向上展开。「资产视图」入口位于缩放控件之前，点击可在画布和资产页间切换。桌面打开节点或素材面板时，整条 Dock 向右让位。「素材库」由左栏直接打开。「撤销」「重做」通过画布菜单或键盘快捷键使用。窄屏保留画布外观、视图切换、选择模式和缩放，整理、连线和小地图进入缩放菜单。
- 节点连线使用同一个开关切换显隐，眼睛图标表示显示全部连线，划线眼睛表示进入隐藏模式。隐藏模式保留当前交互焦点的直接连线。
- 「快捷键」固定在左侧竖栏底部，说明面板紧贴竖栏右侧并与底部对齐。打开时同页展示全部分类，宽屏为四列，窄屏按可用宽度减少列数，内容超高时在面板内滚动。搜索从全部快捷键中筛选。按 `?` 也可以打开，按 `Esc` 关闭时焦点返回按钮。

## 5. 小地图信息表达

小地图用中性色块显示节点的位置和尺寸，用细框标记当前视口。地图范围同时容纳节点和当前视口，视口框在低缩放或远离节点时仍完整显示。平移、缩放时视口框实时更新，拖动框可移动画布，点击框外可跳转。展开的背板以轮廓表示，折叠背板只显示整体色块。小地图按设备像素比渲染。

底部“适应画布”命令的语义是把当前画布内容整体纳入视口，和小地图的导航职责分开：小地图用于定位，适应画布用于一次性恢复内容总览。

## 6. 响应式与交互边界

- 桌面端顶部左右面板保持同一顶部安全区；底部左右面板保持同一底部安全区。
- 窄视口沿用 `--canvas-inset-y + --space-16` 的底部避让规则，避免与移动端底部工具区域重叠。
- 工作模式菜单打开时支持点击外部区域和 `Escape` 关闭。
- `prefers-reduced-motion` 下关闭或缩短面板和选项的进入动画。
- 本次只调整控件位置和视觉层级，不改变菜单命令、模式持久化和画布操作行为。
