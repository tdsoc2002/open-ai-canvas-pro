# 资产库入库规则对齐

创作者在独立图片／视频工作台生成作品后可以直接在资产库找到它们。在画布、短剧、创作参考等流程中产生的工作资源继续留在原处；需要跨项目复用时，再主动保存。

- AC-01：只有按图片／视频工作台类型创建且与同类型产物匹配的已保存结果自动入库；与 LJCanvas 一致，电商中的工作台生成也沿用该规则。普通生成、创作参考、画布登记与短剧等工作资源不自动入库。
- AC-02：资产页新增／上传／导入、画布「保存到资产库」和历史详情中已保存的生成结果可主动入库；重复保存复用原身份。
- AC-03：显式布尔入库标记优先；无有效标记时，仅隐藏已知自动来源：`generation-task`、`canvas-generation`、`canvas-upload`、`short-drama-workflow`、`short-drama`、`previs`、`public-reference-gallery`；保留来源不明或混用的旧条目。
- AC-04：资产分页、计数、全局选择器、本地回退与资产页批量范围一致；不变更按 ID 读取、同步快照、画布、项目或创作历史读取。

非目标：不删除、归档、迁移或批量回写历史数据；不改变对象存储、额度和原文件；不连接真实库跑迁移或写入验证。
