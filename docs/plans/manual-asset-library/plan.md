# 资产库入库规则实施计划

依赖 [需求](./requirements.md) 和 [设计](./design.md)。参考工作区只读，保留本仓既有差异；不提交、推送、运行迁移或部署。

- T-01（AC-01/03/04，DD-01/02；后端；无前置）：资产库查询、计数、投影和自动登记；验收为 SQLite 规则测试覆盖旧分类、分页计数、跨账号和按 ID 保留。
- T-02（AC-02/04，DD-03；后端；与 T-01 独立）：任务输出资产身份查询、路由和测试。口径为 `GET /tasks/:id/output-asset?resourceId=...` 返回 `{ asset }`。
- T-03（AC-01～04，DD-01～03；前端；依赖 T-02 的合同）：明确标记自动和主动入口，过滤本地库及全局选择器，历史增加手动保存；验收为成员规则测试、类型检查和真实组件验证。
- T-04（依赖 T-01～03；协调与独立评审）：复核源入口、过滤范围和权限，记录验证输出和真实环境未覆盖项。
- T-05（AC-02/04，DD-03；依赖 T-04 提出并发风险）：后端资产入库补丁、前端确认合并和浏览器隔离验收。完成条件：只变更入库标记与明确恢复归档状态，预期资源不匹配时拒绝，不传整条缓存记录。
