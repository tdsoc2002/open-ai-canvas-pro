# 资产库入库接口与边界

依据 [验收标准](./requirements.md) 与本机 LJCanvas 实际工作区源码。

- DD-01（AC-01/02）：沿用资产 JSON 的 `metadata.librarySaved`。写入意图随自动或明确保存入口标记；复用原资源、资产身份、用户范围与同步。
- DD-02（AC-03/04）：在 SQLite/PostgreSQL 资产库分页与计数共享成员条件；前端只过滤全局选库和本地回退。按 ID、全量同步、项目内部选择器不使用成员条件。
- DD-03（AC-02/04）：历史按当前结果的资源 ID 查询真实素材，而非猜测生成序号。服务端按用户校验成功任务、资源和结果关联；读接口不写入。画布与历史使用服务端的单条入库补丁；历史写入同时校验预期资源 ID，避免用旧浏览器缓存覆盖项目的新图或主版本。确认响应作为本机同步基线，不将失败报告为成功。

权衡：无旧入库标记且来源混用的条目保留；确认自动来源的条目仅改变列表可见性。无表结构变更或上线操作。
