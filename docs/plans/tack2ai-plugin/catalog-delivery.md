## 配置与保留行为

更新影策后台并随构建放入本轮的 `plugin-packages/tack2ai.yingce-plugin`。从「渠道与模型」创建或打开指向 `https://ai.tack2ai.cn` 的 OpenAI 系统渠道，保存该渠道的 Key，再点**拉取模型**。预览显示协议、能力或不可导入原因。选择后导入，新增条目停用、未定价；管理员另行核对成本、售价和启用范围。以后兼容的新模型只需重新拉取。未覆盖已导入的能力、价格和启停状态。
