# 源点动力影策插件需求

## 目标与流程
按用户最新要求，只接入源点动力网关已有的 OpenAI 通用协议。安装一个 `tack2ai.yingce-plugin` 后，在现有渠道模型中选择文字、图片、视频或语音协议；不修改网关逻辑。

## 验收标准
- AC-01：最终 ZIP 包可被影策真实解析器和安装运行时接受，包含中文说明与完整接口合同，四个 Provider ID 不冲突。
- AC-02：文字使用 Chat Completions，保留历史、系统提示、流式与 Agent 合同。
- AC-03：图片支持生成与参考图编辑及 URL/Base64 结果；音频支持 OpenAI 文字转语音和二进制结果。
- AC-04：视频使用 OpenAI model/prompt/seconds/size 编码；单图 input_reference，复杂参考使用本网关已支持的 references 扩展；查询原任务、鉴权下载 /content。
- AC-05：不发送 X-TD-Contract，不发送 TD 专用 body，不按模型系列分协议；保留失败、空结果和未知状态语义，不自动重新提交收费任务。
- AC-06：交付可直接安装的文件、SHA256、安装步骤和验证记录，真实付费模型未验必须明确说明。

## 非目标与约束
不修改网关、生产宿主逻辑、页面、依赖或线上配置，不读取真实密钥、不调用收费上游、不提交或推送。文字第一版为 Chat Completions；音频为文字转语音，不含音乐、转写、音色克隆。没有拼车管理、草稿转正式和价格/能力自动同步；实际模型与额度由 API Key 和网关配置决定。
