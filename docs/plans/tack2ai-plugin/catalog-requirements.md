# 源点动力统一模型接入需求

## 目标与流程

面向影策管理员。通过一个源点动力系统渠道配置统一地址和 Key。在「渠道与模型 → 拉取模型」预览当前 Key 可见模型，选择导入，核对能力与售价后启用。以后新增模型，只要目录声明了影策已支持的协议和能力，重新拉取即可，不按模型名发新包。

## 验收标准

- AC-01：源点动力渠道通过同一地址和服务端已有 Key 读取 `GET /v1/catalog/models`；预览不写库，不返回密钥；模型 ID 按网关返回值提交。
- AC-02：导入时以服务端重取的目录为准。可识别模型自动预填调用协议、网关明确声明且宿主可表达的能力与限制；至少覆盖文字、像素/档位图片、视频和语音。不同能力不按模型名或供应商名称推断。
- AC-03：在现有生成执行器上补齐已知通用协议差异：图片像素尺寸与档位/比例分别编码，视频固定时长及参考素材按目录约束，语音不强制塞入未经确认的默认音色，并覆盖宿主能表达的参考素材。公开目录的能力描述不等于可以任意透传上游字段。
- AC-04：不覆盖现有模型、价格及启停状态；同一模型重复导入不新增；新条目默认停用、未定价。未知协议、冲突或关键能力不可表达时清楚显示原因，不能当成可用配置导入。
- AC-05：使用真实插件解析器、影策后台导入和模拟网关验收。使用从未出现在代码中的模型 ID，验证变更模型 ID 不需要修改插件；覆盖失效 Key、目录变化、重复导入、价格与启停不被改写。重新打包并校验 `1.0.0` 制品与源文件一致。

## 非目标与约束

- 不改源点动力网关，不修改其他渠道的发现逻辑，不动个人渠道、不加定时同步。
- 首版限定当前官方统一出口 `https://ai.tack2ai.cn`；其他地址仍保留影策现有手工配置能力，不自动按源点动力发现。
- 不自动导入公开价格、不猜测账号成本、不改变计费计算规则；需要动态报价、复杂附加费或者全新协议的模型，不承诺仅凭目录就能直接启用。
- 不自动提交、部署、重启或进行真实收费生成。版本统一沿用 `1.0.0`。
