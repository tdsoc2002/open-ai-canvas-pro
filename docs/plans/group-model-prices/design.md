# 用户分组模型专属单价设计

关联 [需求](requirements.md)。

- DD-01（AC-01、AC-05）在现有分组编辑器加入专属单价，系统渠道显示价格档，前台显示统一价模型。专属价作为分组模型配置的另一种记录保存在现有 JSON 列，以稳定 ID 区分目标。服务端核对目标、计费模式、价格结构和适用条件。
- DD-02（AC-02、AC-03）目录投影与账单构建共用匹配逻辑。专属价以微积分存储，采用 1 倍倍率和积分兑换基准。按次、按秒和 Token 使用专属单价字段，图片采用输入和像素档位单价，启用参考视频计价时保留其专属价。
- DD-03（AC-04）使用现有账单价格快照结算。模型或规格改价时直接单价独立生效，计费模式和适用结构失配时提示重新配置。渠道价前台模型先匹配原始规格再校验分组价格，切换供应线路时按新线路价格原子调整预留并替换价格快照。
- DD-04（AC-06）有适用专属价时，在专属价线路内按路由优先级筛选，使用账号和前台模型标识作为稳定的加权选择键。短时熔断不改变已选专属价线路。此规则覆盖报价与首次建单。模型配置变更与已创建任务的故障切换继续遵循现有价单和路由规则。
- DD-05（AC-07、AC-08）分组更新比对持久化的前一版价格。仅校验新增或已改动的价格，原样保留的失效项仍可读取和删除。审计记录价格目标与前后值，分组写入按读取的版本进行冲突检查并与审计原子提交。

价格为有界非负整数。显式零价用零表示，缺失字段校验失败。管理员权限由现有管理服务检查，渠道权限在定价前检查。保存复用分组事务和缓存失效，无数据表迁移。
