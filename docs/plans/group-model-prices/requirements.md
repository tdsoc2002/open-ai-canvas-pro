# 用户分组模型专属单价需求

管理员可以为一个用户分组中的指定模型直接填写积分单价。使用专用分组时，管理员可以把定价应用到一个账号。

- AC-01 管理员可选模型或规格，按该模型已有计费单位录入专属单价，并在重开分组编辑时看到保存的值。
- AC-02 系统渠道按渠道模型和价格档匹配，统一价前台模型按模型匹配。专属价直接用于目录、报价和账单预留，且保留用量规则。
- AC-03 支持按次、按秒、Token 和图片用量价格。参考视频价按启用状态填写。同档文本的专属 Token 价格覆盖分时代价。
- AC-04 移除专属价后恢复原有计价。已创建账单在结算时使用订单快照，渠道权限和上游成本规则沿用现有合同。
- AC-05 服务端拒绝重复目标、缺失价格、无效金额及与目标不符的配置。不同分组及同名渠道模型价格隔离。
- AC-06 跟随渠道价的前台模型有专属价线路时，同一分组用户对同一规格的报价和首次任务预留选用同一条专属价线路。普通价线路恢复不改变此选择，选中的专属价线路短时熔断时提示暂不可用。
- AC-07 失效的历史专属价可原样保留或删除，分组其他资料仍可保存。新增或修改的价格按当前目标校验。
- AC-08 分组价格新增、修改、移除的审计记录包含对应目标和前后价格，并与分组写入同事务提交。

范围限系统模型使用扣费和现有分组管理。沿用积分精度、结算舍入和渠道线路换价规则。
