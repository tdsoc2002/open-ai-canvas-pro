# MiniMax H3 视频计费设计

依据同目录的需求文档。

- DD-01（AC-01、AC-02）在渠道规格加入 `minimax_h3`，由上游型号与分辨率选择费率及免费张数。规格输出单价作为基准，输入价按其相对官方输出价的倍率同步换算。渠道币种为 CNY 且填入官方输出价时按官方人民币费率算价，成本基准按现有积分口径配置。
- DD-02（AC-03）沿用系统渠道报价及任务入队订单入口。报价可采用已知或预估时长，实际任务读取已归一化图片引用并实测输入视频。订单锁定金额和用量，成功结算与退款走现有流程。
- DD-03（AC-04）成本核算独立保存金额快照，在统一售价线路切换中复用同一计价函数。专属计费仅由渠道规格启用，前台统一价继续采用自身价格策略。
- DD-04（AC-05、AC-06）H3 价格档增加可空按次售价。真实任务从服务端选中的价格档冻结 IR 开关到协议绑定，账单冻结费用到授权快照；适用直连和跟随渠道价的标准版 `minimax-video`。用户分组专属输出单价只作用于视频价，IR 使用自身价格及渠道币种折算。
- DD-05（AC-06）在现有视频协议的创建请求发出前，复用已编译的素材与鉴权调用 `/v2/h3_context_ir`，查询 `h3_context_ir` 结果后替换提示词。IR 任务 ID 不写入视频任务 ID，沿用宿主出站策略和轮询机制。已发起 IR 且提交状态不明时保留已有的防重发保护。
- DD-06（AC-07）源点动力公开合同的上游键为 `minimax h3`，支持 4–15 秒的 `/v1/videos` 请求。公网验证确认该型号要求 `td.video.v1`，受管型号使用原生请求合同，把冻结的布尔开关放入 `parameters`，轮询仍按上游视频任务 ID 执行。无需新增迁移。
- DD-07（AC-08）为 `tack2ai-video` 的 `minimax h3` 增加专属分辨率费率，复用视频与参考素材、IR 订单快照。源点动力开发库已发布的规则作为本地配置的依据，公网账户费用以该账户实际报价或账单为准。

无匹配费率、无有效输出时长或无法实测输入视频时拒绝下单。数据库变更使用独立的追加迁移，由项目原有发布机制执行。

开启 IR 的生成任务须满足官方 4–15 秒限制。视频和增强组成一次影策提交，不单建用户 IR 账单。IR 按次费用与视频费用在创建时一并预授权，按原有任务结果结算或退款。
