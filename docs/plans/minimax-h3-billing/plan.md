# MiniMax H3 视频计费实施计划

- T-01（DD-01、DD-02）由 Codex 实现费率与规格校验、报价和预扣，在计费入口验证免费边界及媒体时长。
- T-02（DD-03，依赖 T-01）由 Codex 实现成本快照、线路切换持久化与数据库增量迁移，检查旧订单语义。
- T-03（DD-01、DD-02，依赖 T-01）由 Codex 实现渠道价格编辑、报价说明和项目文档，核对各入口的字段。
- T-04（依赖 T-01 至 T-03）核对完整差异及相关计费路径，记录专项验证结果。
- T-05（DD-04）由 Codex 接入 IR 规格价格、后台表单、报价及订单快照，验证关闭、免费及正价。
- T-06（DD-05，依赖 T-05）由 Codex 接入协议执行、校验和文档，验证 IR 只提交一次、增强后的提示词确实用于生成、失败阶段不会提交视频。
- T-07（DD-06，依赖 T-05）由 Codex 接入源点动力按次和按秒档位的 IR 附加价、报价和协议开关。验证留空、免费及正价，并确认原请求只提交一次且模型 ID、元数据与网关合同匹配。
- T-08（DD-07）由 Codex 核对源点动力已生效费率，接入四档 H3 专属计费，验证参考素材、IR 和预扣金额，再配置本地模型并核对最小实测订单。
