# MiniMax H3 视频计费需求

渠道管理员可以为 H3 视频模型按分辨率选择官方计价口径。创作者在提交前按实际素材获得报价。

- AC-01 每次任务标准版、Highspeed 和 Lite 前 5 张输入图片免费，Max 前 2 张免费。按档位分别计输出视频秒、输入视频秒及超额图片张数，输入音频免费。
- AC-02 管理员显式开启 H3 计费并可采用国内官方单价。其他渠道现有定价与历史订单继续按其配置执行。
- AC-03 直连及跟随渠道价的前台模型报价与预扣同口径。结算使用下单快照，任务失败沿用原有退款流程。
- AC-04 成本可单独设置，供应线路切换时使用目标线路快照。
- AC-05 管理员可给 MiniMax-H3 标准版规格填写 H3-Context-IR 每次售价。留空时关闭，显式填写 0 时启用并免收影策 IR 费用。售价使用规格所在模型的计价货币。
- AC-06 开启后对原始素材调用一次 IR，拿到增强提示词后提交视频。报价单列折算后的 IR 费用，成功交付时在视频账单里一并收取，缺余额时在提交上游前阻止。等待和失败遵循既有订单规则，状态不明时避免自动重发。
- AC-07 源点动力 `minimax h3` 使用已配置的视频价格档，管理员可叠加 IR 每次售价。受管请求使用 `td.video.v1` 原生合同，启用后同一次 `/v1/videos` 请求带 `parameters.context_ir_enabled=true`。留空时关闭增强，配置 0 时增强且免收影策 IR 费用。
- AC-08 源点动力 `minimax h3` 可以选用 H3 专属计费。按所选分辨率分别计输出和输入视频时长，扣除首 5 张免费参考图，并叠加一次 IR 费用。价档使用已核实的渠道费率。

规则依据为 MiniMax 国内 API 定价文档。第三方渠道费用和已部署渠道参数由管理员核对，本次范围为工作区实现。

IR 按次金额由站点管理员填写。MiniMax 官方上游按实际 Token 结算，本次实现的是影策侧按次售价。
