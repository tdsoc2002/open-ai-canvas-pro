# 团队创作媒体生成需求

## 目标与用户

团队成员在创作页选择系统图片或视频模型，设置参数和参考素材，确认积分上限后发起生成，在原对话中查看结果。

## 验收标准

- AC-01 个人和团队创作页复用模式、模型、参数与提交逻辑。团队支持文本、图片和视频。
- AC-02 单次或多图请求确认后才建立任务。同一图片批次含独立任务，每项有独立的提交标识。
- AC-03 报价使用成员可用的系统模型价格，只冻结和结算本人在当前团队获配的额度。额度不足、报价上涨或成员授权失效时明确拒绝。
- AC-04 图片、视频、参考文件及任务归当前空间。团队素材访问需要成员身份。

## 约束

复用团队任务、钱包和媒体存储合同。团队仍使用系统模型。Agent、自定义渠道、公开视频资源和生产发布不在本次范围。仅接受已就绪的本团队资源作为媒体参考，要求公网 URL 的供应商参考模式受团队资源权限限制。
