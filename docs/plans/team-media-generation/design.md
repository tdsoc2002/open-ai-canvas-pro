# 团队创作媒体生成设计

对应 [需求](requirements.md)。

- DD-01（AC-01）使用现有创作页和生成任务模块。团队模型目录筛选可计费的文本、图片和视频系统模型。团队文本引用仍从团队库插入文本。
- DD-02（AC-02、AC-03）前端继续使用团队报价接口。多图共享一次最高费用确认，每项仍独立提交，后端逐项重算费用并强制上限。
- DD-03（AC-03）团队入口校验成员并限制输入在创作类型和参数范围内。准入用成员解析模型和报价，使用空间键读取参考、检查容量和持久化任务。订单绑定成员的团队账，沿用冻结、结算、退款和备用线路上限。
- DD-04（AC-04）以资源 ID 校验媒体类型、归属与就绪状态。默认可内联的协议从团队存储读取文件传给系统供应商，继续通过鉴权路径向浏览器交付作品。

接口沿用团队 `/workspace/tasks/quote` 和 `/workspace/tasks`，无数据库结构变更。素材、账务和任务均按现有空间权限处理。
