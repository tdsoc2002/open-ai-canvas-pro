# 平台统一提供存储和模型：需求

- AC-01：关闭用户自有存储时，所有个人供应商的设置保存和连接测试请求都被后端拒绝；新上传及新生成作品选择平台存储，包括平台明确设为本地时。
- AC-02：不自动删除、搬迁或重绑历史资源；原凭据仍可用时，历史资源沿原位置读取。
- AC-03：用户设置在未获授权时不展示个人存储入口或表单；管理员可以显式启用，默认关闭。
- AC-04：模型沿用现有后台控制：关闭自定义渠道；仅开放经管理员配置的模型；不依赖隐藏按钮实现限制。若启用独立的个人工作流，也需单独关闭其平台开放。
- AC-05：交付代码及受影响的测试；核对 3000 当前平台存储和模型配置。无平台模型或无法验证时，不静默切断所有生成能力。3010、服务器部署和数据库迁移不在范围。
