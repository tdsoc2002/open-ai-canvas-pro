# 平台统一提供存储和模型：设计

- DD-01（AC-01、AC-03）：把 S3 专用开关升级为 `allowUserStorage`，存于现有平台 OSS 设置 JSON；缺省为 false，旧 S3 字段不自动放宽到全部供应商，无结构迁移。测试连接与保存先读平台许可再处理个人配置。
- DD-02（AC-01、AC-02）：新资源共用既有存储选择器，禁用时不读取个人配置；历史对象继续从其存储绑定或历史记录解析，不改资源读、播放和清理路径。
- DD-05（AC-01、AC-02）：新的平台对象使用实际 `storage_locations` 绑定；平台非 S3 配置缺少位置 ID 时按当前平台连接与凭据生成可复用的加密位置，防止同桶历史上的个人凭据接管后续读取和重试。不改旧资源绑定。
- DD-03（AC-03）：账号设置通过现有个人存储读取接口取得平台许可，未确认许可或读取失败时不展示入口。设置表单复用返回值；后端为最终校验边界。
- DD-04（AC-04、AC-05）：保留现有模型来源与用户分组配置机制，不创建真实模型凭据、不盲目切换目录或关闭所需模型。核对 3000 的配置并在已验证的可用范围内落地。
