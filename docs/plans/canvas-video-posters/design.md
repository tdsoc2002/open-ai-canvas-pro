# 画布视频自动封面设计

依据 [需求](requirements.md)。当前素材插入会丢掉原有封面，缩略模式只读已有封面，图片解析失败也不会触发补图。

- DD-01（AC-01）：素材选择器和生成结果把已有封面传入节点的 `previewContent`；旧节点可从关联的同资源素材读取封面，不使用不同版本或视频本身的地址充当封面。
- DD-02（AC-02）：两种画布显示档位复用同一封面组件。缺图或图片读取失败时，进入视口后复用现有串行抽帧和小图保存；旧请求不得覆盖新媒体或并发写入的新封面。
- DD-03（AC-03）：移除悬停自动播放入口，保持点击播放。抽帧可读取一次视频数据，但已有可用封面的节点只加载图片。原视频不可访问、浏览器不支持编码或禁止读取像素时保留占位；不新增视频转发接口。
