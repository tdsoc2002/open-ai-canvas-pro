# 画布视频自动封面需求

创作者打开画布后，不必重新上传视频就能辨认已有和新增的视频节点。

- AC-01：素材已经有图片封面时直接沿用，不为预览请求视频。
- AC-02：可读取画面的无封面视频，在画布中按需截取并保存小图；已失效的封面可重新生成。
- AC-03：节点默认显示静态图，正常比例下点击播放按钮才启动播放器；不可读取画面时保留占位和播放入口。
- AC-04：平台已保存的原视频不依赖浏览器跨域权限即可补封面；只保存小图，同一资源重复请求复用封面。验收目标为「样板镜 1」重进画布后仍显示首帧。

不迁移历史数据，不绕过跨域或鉴权限制，不改后端和存储配置；历史封面随画布访问补齐，不后台扫全库。
