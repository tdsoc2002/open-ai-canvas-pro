# 画布文件夹设计

依据 [需求](./requirements.md) 实施。

- DD-01（AC-01、AC-03）在画布域保存工作空间的目录记录，`canvas_projects.folder_id` 保存位置，空字符串表示首页。个人账号和团队空间复用现有内容归属键。文件夹删除和成员归位同事务，移动先锁定目标文件夹再更新空间内的画布。批量更新数与去重后的请求数一致才提交。
- DD-02（AC-02）归档为独立 API。画布文档保存只更新原有列，因此编辑、历史或资源操作与归档位置独立。服务端限制批量请求大小，写入失败返回现有错误信封。
- DD-03（AC-01、AC-04）列表沿用服务端分页，在计数和分页前按目录筛选。首页展示目录卡片和未归档画布，输入关键词或选择项目筛选后在整个画布库查找。目录用列表路由查询参数表示，文件夹页面显示返回首页的入口。新建与导入入口集中在首页。
- DD-04（AC-02、AC-03）复用画布卡片菜单、选择栏、列表网格和产品弹窗。保存成功后刷新当前空间的目录与画布查询，失败保留弹窗和操作对象。

迁移只增表、列和索引，历史行自动落在首页。后端启动要求与迁移账本版本匹配，回退旧版时使用升级前备份，升级后新增的目录和画布移动记录会随回退丢失。
