# 画布文件夹需求

## 目标与流程

创作者可在「我的画布」创建文件夹，把已有画布移入，再打开文件夹继续编辑画布。个人空间和团队空间各自管理目录。

## 验收标准

- AC-01 创建、打开和重命名一级文件夹。刷新后，目录与归档结果从服务端恢复。
- AC-02 桌面端可从画布封面拖放到文件夹。画布菜单和多选工具栏也可移动画布，包括移回画布库首页。画布内容和所属业务项目保持原样。
- AC-03 删除文件夹前确认，目录内的画布全部移回首页。目标文件夹和要移动的画布必须属于当前空间，任何一项缺失都使整批移动失败。
- AC-04 历史画布默认在首页。首页搜索和业务项目筛选可找回已归档画布，文件夹内的搜索和筛选限定当前目录。保留原画布新建、导入和排序。

## 范围与风险

目录为一级，组织已有的云端画布。新建和导入画布仍以首页为入口。归档位置独立于画布正文、快照和导出文件。需验证历史数据迁移、批量权限边界和移动与删目录的并发顺序。
