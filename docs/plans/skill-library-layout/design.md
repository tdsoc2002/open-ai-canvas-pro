# 技能库整页布局对齐设计

对应 [需求](./requirements.md)；以本地 LJCanvas 的技能库为结构参考，保留当前已有业务行为。

- DD-01（AC-01）：顶部用两个范围入口「技能广场 / 我的技能」，个人范围内用下拉切换全部、我创建的和我的收藏；分类下拉、搜索和排序复用已有控件，安装和行业推荐仍为工具栏操作。卡片组件不改。
- DD-02（AC-02、AC-03）：分类选项来自现有接口结果，继续调用原切换函数和查询参数。策展子分类显示所属根；只有原来可管理的技能库范围显示管理分类；删除条目继续限制个人分类或管理员。读取失败的重试提示移到结果区顶部。
- DD-03（AC-01、AC-03）：仅调整技能库页面及其样式，不改共享工具栏或后端。浏览器使用独立测试数据，不执行真实技能或分类写入。
