# 资产库卡片与预览需求

创作者在资产页浏览不同种类的素材，先看封面，再按需查看素材详情或执行单条操作。参考本地 LJCanvas 的卡片信息层级和居中预览。

- AC-01：卡片以不裁切的方形封面为主；名称、更新时间、编辑和更多操作在封面下方，媒体规格留在详情，回收站卡片仍显示保留提示。保留封面、名称点击预览及勾选、Shift/Ctrl 多选。
- AC-02：预览在居中弹窗展示，桌面左侧预览、右侧信息，窄屏改为纵向布局。保留原图查看、缩放，视频和音频播放，文本内容及复制，模型文件信息和下载，角色设定及音色。关闭或切换素材后不保留上一素材的缩放和播放器。
- AC-03：保留方舟认证与管理链接、存储及项目来源信息、现有筛选、上传、分页、批量和回收站行为。不同主题下应可读，焦点与键盘导航可用。
- AC-04：资产页按 LJCanvas 重新排布：第一行是类型和创建操作，第二行是搜索、业务分类、我的分类、密度和多选，移除固定分类栏。购买空间和回收站从「更多」直达，账号容量仍可在账户菜单查看。列表和空态均占满下方内容区。

非目标：不迁移 LJCanvas 的后台、账号、素材数据或额外功能；不修改 API、上传、删除、方舟认证提交、授权和存储规则。真实登录数据与写入流程不作为前端排版测试前置条件，不运行真实写操作。
